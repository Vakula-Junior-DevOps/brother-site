# brother-site

Односторінковий сайт-візитка (німецькою мовою) для бізнесу брата.
Чистий HTML + CSS + JavaScript: без фреймворків, без збирачів, без зовнішніх підключень (DSGVO).

Правила роботи: `CLAUDE.md`. Покроковий план: `PLAN.md`.

## Структура

| Шлях | Що там |
|---|---|
| `index.html` | головна сторінка (розділи `#home`, `#services`, `#contact`) |
| `impressum.html`, `datenschutz.html` | обов'язкові юридичні сторінки |
| `css/style.css` | усі стилі |
| `js/main.js` | бургер-меню |
| `img/` | фото та SVG-заглушки |
| `fonts/` | (пізніше) локальні шрифти `.woff2` |

## Як запустити локально

**Варіант 1. VS Code + Live Server**
1. Відкрити папку проєкту у VS Code.
2. Праворуч унизу натиснути **Go Live**.
3. Сайт відкриється в браузері й оновлюватиметься після кожного збереження файлу.

**Варіант 2. Python**
```bash
python -m http.server 8000
```
(на Linux/macOS команда `python3`). Далі відкрити http://localhost:8000

## Як оновити сайт

1. Змінити потрібні файли й перевірити результат локально.
2. Зберегти зміни в git і відправити на GitHub:
   ```bash
   git add .
   git commit -m "fix: короткий опис змін"
   git push
   ```
3. GitHub Pages сам опублікує нову версію протягом кількох хвилин.
