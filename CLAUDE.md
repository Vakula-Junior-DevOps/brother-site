# CLAUDE.md — контекст проєкту для Claude Code

## Що це за проєкт
Односторінковий сайт-візитка для бізнесу мого брата (клієнт, Німеччина).
Тематика бізнесу: **Hausmeisterservice** (майстер по дому: дрібний ремонт, монтаж, сад, зимова служба тощо).
Точна назва фірми, тексти, фото й контакти ще невідомі, тому зараз контент — **тестові заглушки на цю тему**
(німецькою, з явно вигаданими даними на кшталт `Musterstraße 1`, `+49 000 0000000`).

Сторінка складається з 3 розділів, що йдуть один під одним:
1. `#home` — титульний розділ із загальною інформацією (великий банер).
2. `#services` — послуги: картки з фото, назвою та коротким описом.
3. `#contact` — контакти (телефон, email, WhatsApp, адреса).

Окремо є дві юридичні сторінки, обов'язкові в Німеччині: `impressum.html` і `datenschutz.html`.

Покроковий план роботи лежить у `PLAN.md`. Працюй строго за ним.

## Технічні рамки
- **Тільки HTML + CSS + чистий JavaScript.** Без фреймворків (React, Vue, Bootstrap, Tailwind), без npm, без збирачів (build tools). Сайт має відкриватися простим відкриттям файлів.
- **Жодних зовнішніх підключень:** ні CDN, ні Google Fonts, ні Google Maps iframe, ні аналітики, ні трекерів, ні cookies. Причина: німецьке законодавство про захист даних (DSGVO). Усе має лежати в репозиторії.
- Шрифти: спершу системний стек шрифтів (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`). Власний шрифт додаємо пізніше, тільки локально у форматі `.woff2`.
- Мова сайту — **німецька**: `<html lang="de">`, тестові тексти теж німецькою. Коментарі в коді — **українською**, короткі, щоб я розумів, що робить кожен блок.
- Фото-заглушки: створюй прості локальні SVG у `img/` (сірий прямокутник з підписом). Не підвантажуй картинки з інтернету.
- Підхід **mobile-first**: спершу стилі для телефона, потім `@media (min-width: ...)` для більших екранів.
- Кольори, відступи та шрифти задавай через CSS-змінні в `:root`, щоб тему можна було змінити в одному місці.
- Семантичні теги: `header`, `nav`, `main`, `section`, `footer`. У кожного зображення має бути `alt`. Текст має бути контрастним до фону.
- Плавну прокрутку роби через CSS (`scroll-behavior: smooth`). JavaScript тільки там, де без нього не обійтися (бургер-меню).
- Для порад щодо HTML/CSS/JS використовуй skill modern-web-guidance
  (виклики npx для нього дозволені — це інструмент агента, а не частина сайту).
- Використовуй лише можливості зі статусом Baseline "Widely available",
  щоб сайт працював у всіх поширених браузерах.

## Юридичні тексти
- **Ніколи не вигадуй** юридичні тексти чи персональні дані (ім'я, адресу, податкові номери).
- На сторінках Impressum і Datenschutz створюй лише структуру з плейсхолдерами на кшталт `[HIER TEXT AUS DEM GENERATOR EINFÜGEN]` і `[NAME]`, `[ADRESSE]`.
- Тексти я згенерую сам (наприклад, через e-recht24.de) і вставлю.
